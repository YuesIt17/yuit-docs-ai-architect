Рекомендация

Llama-3-70B INT4 (AWQ/GPTQ) + vLLM на 2× NVIDIA A100 80GB · OpEx ≈ 463–464k ₽/мес на Yandex / Cloud.ru. AWS per-GPU ≈ тот же порядок; GCP ~1.5× дороже. Для RetailPartnerX (152-ФЗ) — RU-облака.

  • FP16 ≈ 188 GB VRAM → минимум 3× A100 80GB
  • INT4 ≈ 83 GB → 2× A100 с запасом под 1000 RPM
  • INT4 + vLLM: экономия ~30–40% vs FP16 baseline
  • T4 не рекомендуем; L4 — только кластер ≥4 карт

2. VRAM = Weights + KV Cache + overhead

VRAM_GB = N_params × bytes_per_param / 1e9 + (0.3125/1024) × seq_len × concurrent + overhead
Режим Weights KV (67×2k) Overhead Σ VRAM
FP16 (2 B/param) 140.0 GB 42.9 GB 5.0 GB ≈ 187.9 GB
INT4 (0.5 B/param) 35.0 GB 42.9 GB 5.0 GB ≈ 82.9 GB

INT4 режет веса в 4 раза; KV при высокой concurrency остаётся крупным — поэтому batching / PagedAttention критичны.
